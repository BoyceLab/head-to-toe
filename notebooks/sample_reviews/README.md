# Sample review files

Invented reviews for trying the combining notebook before real reviews arrive. The reviewers are placeholders, and the decisions in the second and third files were generated at random, so the results mean nothing.

To try them, set `SOURCE = "folder"` and `LOCAL_FOLDER = "sample_reviews"` in the notebook's settings cell, or upload all three files in Colab.

Do not add real reviews to this folder. Real reviews can include reviewers' names.
